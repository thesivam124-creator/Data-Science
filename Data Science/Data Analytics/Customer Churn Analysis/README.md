# 📊 Customer Churn SQL & Data Analytics

An exploratory data analytics project that leverages SQL database queries and Python data visualization libraries to analyze customer behavior, identify churn patterns, and extract business retention insights.

## 🚀 Key Components
- **SQL Database Integration**: Querying SQLite database (`customer_churn.db`) schema and tables dynamically via `sqlite3` and `pandas`.
- **Data Cleaning & Preprocessing**: Handling missing values, data type casting, and schema normalization.
- **Exploratory Data Analysis (EDA)**: Visualizing customer demographics, subscription tenure, and churn risk factors using `Seaborn` and `Matplotlib`.
- **Data Export**: Processed churn dataset exported as `exported_churn_data.csv`.

## 🛠 Tech Stack & Tools
- **Database**: SQLite3 (`customer_churn.db`, `test_database.sqlite`)
- **Libraries**: Pandas, NumPy, Matplotlib, Seaborn, SQLite3
- **Environment**: Jupyter Notebook
