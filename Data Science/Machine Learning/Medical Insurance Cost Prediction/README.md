# 🏥 Medical Insurance Cost Prediction

A Machine Learning analysis and regression project predicting individual medical insurance costs based on demographic and health attributes.

## 🚀 Highlights
- **Exploratory Data Analysis (EDA)**: Visualizing relationships between age, BMI, smoking status, region, and charges.
- **Predictive Modeling**: Regression models estimating healthcare costs.
- **Dataset**: `insurance.csv`
