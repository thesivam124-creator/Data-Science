# 🎬 CineSage & Model Integration (genai1)

An exploration of LLM Chat Models, Embedding Models, and the **CineSage** movie recommendation interface.

## 🚀 Components
- **CineSage**: Interactive core and UI for AI-powered movie exploration.
- **Chat Models**: Integration wrappers for OpenAI Chat completion models.
- **Embedding Models**: Vector embedding generation for text representation.

## 🛠 Setup & Running
```bash
pip install -r requirement.txt
python test.py
```
