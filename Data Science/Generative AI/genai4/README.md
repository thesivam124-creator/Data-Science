# 🤖 Multi-Agent Web Research Pipeline (genai4)

A multi-agent autonomous workflow that searches the web, scrapes content, synthesizes research, and generates structured articles.

## 🚀 Components
- **`agents.py`**: Specialized AI Agents (Search Agent, Scraping Reader Agent, Writer Agent).
- **`pipeline.py`**: Orchestrates sequential agent collaboration.
- **`tools.py`**: Web search and URL scraping tools.
- **`app.py`**: Streamlit web interface for interactive research generation.

## 🛠 Setup & Running
```bash
pip install -r requirements.txt
streamlit run app.py
```
