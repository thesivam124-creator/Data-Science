# 🤖 Generative AI Projects

A collection of Generative AI applications and experiments covering Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), LangChain Expression Language (LCEL), and autonomous Multi-Agent systems.

## 📂 Projects Overview

| Project | Description | Key Tech Stack |
| :--- | :--- | :--- |
| [**genai1**](./genai1/) | CineSage Movie Recommendation UI, Chat Model wrappers & Embedding Model experiments | Python, OpenAI, Embeddings |
| [**genai2**](./genai2/) | Document Loaders, Retrievers, and Chroma Vector Store RAG Pipeline | LangChain, ChromaDB, RAG |
| [**genai3**](./genai3/) | LangChain Runnables (LCEL), Parallel Execution, Custom Tools & News Summarizer | LangChain, LCEL, Agents |
| [**genai4**](./genai4/) | Multi-Agent Web Research & Automated Writing Pipeline UI | Streamlit, LangChain, Web Scraping |
