# ⚡ LangChain Runnables & Tool Agents (genai3)

Hands-on experiments with LangChain Expression Language (LCEL), Runnable Sequences, Parallel Execution, and Custom Tool Calling.

## 🚀 Components
- **`Agents.py`**: Agent setup with dynamic tool invocations.
- **`newssummarizer.py`**: News extraction and summarization agent.
- **`parallelrunnable.py` & `sequencerunnable.py`**: Advanced LCEL workflows.
- **`toolcalling.py` & `owntool.py`**: Custom python tools bound to LLM calls.

## 🛠 Setup & Running
1. Configure credentials:
   ```bash
   cp .env.example .env
   ```
2. Run desired scripts:
   ```bash
   pip install -r requirements.txt
   python Agents.py
   ```
